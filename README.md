# Qatar Foundation Admin Portal

## 🚀 Overview
A full-stack admin portal built using Flask for backend and a pre-built frontend UI.

## 🔐 Features
- Admin Signup & Login (Flask-Login)
- Secure Password Reset (Token-based, console link)
- CRUD Operations for Opportunities
- Dynamic UI (No page refresh)
- User-specific access control

## 🛠 Tech Stack
- Python (Flask)
- SQLite
- HTML, CSS, JavaScript

## ▶️ How to Run

```bash
git clone https://github.com/vathsavvarma/qatar-admin-portal.git
cd qatar_admin_backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
